UDI reference

The data on every compliant label.

Five building blocks your teams will recognize in the webinar — sample values only, for learning. Not a real device record.

(01) UDI-DI (01) 09506000123457 (17) EXP 271231 (10) LOT LOT-88421 (21) S/N SN-00931 HRI Exp 2031-12-31 AIDC GS1 · HIBCC · ICCBBA BASIC ++BASICUDI123456789X (01) UDI-DI (01) 09506000123457 (17) EXP 271231 (10) LOT LOT-88421 (21) S/N SN-00931 HRI Exp 2031-12-31 AIDC GS1 · HIBCC · ICCBBA BASIC ++BASICUDI123456789X
01
UDI-DI Device Identifier
(01) 09506000123457

Fixed identity for a device model and packaging level. Scanners and databases use this first to know which product they are looking at.

02
UDI-PI Production Identifier
(17) 271231   (10) LOT-88421   (21) SN-00931

Variable production data — expiry, lot/batch, and serial when required. Fields depend on device type and risk class.

03
HRI Human-readable
Exp: 2031-12-31 · Lot: LOT-88421 · S/N: SN-00931

Plain-language text that must match the coded UDI so people can verify the same facts if a scanner is unavailable.

04
AIDC Barcode / 2D
Machine-readable carrier · GS1 / HIBCC / ICCBBA

Automatic Identification and Data Capture encodes the UDI for systems across manufacturing, logistics, and clinical use.

05
Basic UDI-DI EU device group
++BASICUDI123456789X

EU key for a device group in technical documentation and EUDAMED — not the primary on-pack barcode, but it must stay aligned with the UDI-DI story.
